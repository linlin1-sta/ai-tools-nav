常见问题

这些工具都免费吗？▾

卡片上都标了：标「免费」的可以一直免费用；标「免费 + 付费」的有免费版或免费额度，进阶功能收费；标「付费」的需要订阅。价格和额度各家调整频繁，以官网为准。

哪些在国内能直接打开？▾

国产工具——DeepSeek、Kimi、豆包、通义千问、智谱清言、讯飞星火、即梦AI、可灵AI、秘塔AI搜索——国内直连就能用。ChatGPT、Claude、Gemini、Midjourney、Runway、Perplexity、Suno、ElevenLabs、Cursor、Gamma、DeepL 等海外工具有地区限制，具体以各官网公布的支持地区为准。

对话助手这么多，先用哪个？▾

只想免费、打开就用：DeepSeek 或豆包。经常读长文档：Kimi。写代码和啃英文资料：Claude 或 ChatGPT。没有哪个全能，按你手头最常干的那件事选一个先用起来。

这个导航怎么选工具？▾

只收三类：官方产品（链接一律指向官网）、有真实用户量、还在持续更新。同类只留头部几个，不收套壳站和镜像站。全部链接定期复查，失效的及时下架。

Agent 工具和普通聊天 AI 有什么不一样？▾

聊天 AI 是你问一句它答一句；Agent 是你给一个目标，它自己拆步骤、调用浏览器和工具、跑完再交成品。想「一句话拿结果」用 Manus、Genspark；想自己搭一个专属助手用扣子 Coze 或 Dify；想把 AI 塞进现有业务流程用 n8n；派它写代码用 Devin、Lovable。

GitHub 排行榜多久更新一次？数据准吗？▾

每周一期。每一期的数据都来自 GitHub 官方 Trending 周榜，本周新增 Star 按该页显示值排序，总 Star 和 Fork 再用 GitHub API 逐个核对，抓取日期标在榜单标题旁。本页是静态页面，不会自动刷新，看到的永远是标注日期那一期的快照；想看实时榜单，点榜单下方的 GitHub Trending 链接。

Skills 是什么？怎么给 Claude 装技能？▾

Skill 就是一个装着说明书、脚本和模板的文件夹（核心是一个 SKILL.md），装上后 Claude 遇到对口任务会自动按里面的规矩干活，比如按你公司的格式出 Word、做数据分析。入门先看 Claude Skills 官方页和 Anthropic 的 GitHub 技能仓库；想淘更多，去 SKILLS.pub、Claude Skills Hub 这类市场按分类搜，照各仓库说明安装即可。
